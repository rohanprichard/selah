# Security Policy

## Supported Versions

Currently, only the latest version of Selah on the `main` branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within Selah, please report it privately.

**Do not open a public issue.**

Instead, please send a message through [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature on this repository. 

We will strive to acknowledge your report within 48 hours and will keep you informed of our progress towards a fix and an announcement.

Thank you for helping keep Selah secure!
